# Face Detection with OpenCV

This simple computer vision project performs face detection on a static image using OpenCV's Haar Cascade Classifier.

## How it works:
- Load an image.
- Convert it to grayscale.
- Apply a pre-trained Haar Cascade classifier to detect faces.
- Draw rectangles around detected faces.
- Display the final image in Google Colab.

## Requirements:
- opencv-python

## Run:
Upload an image to `/content/` named `sample_face.jpg` and run the notebook.
